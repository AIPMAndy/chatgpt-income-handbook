# 赚钱计算器方法论：营收、现金结余与劳动价值

> 本公式只做**情景演算**；没有市场抽样、成交预测、税务核算或法律适用性判断。所有输入参数由使用者自己负责。金额为人民币演示单位。

## 必须分开的八个概念

1. **报价**：向客户拟议的合同金额，不代表已签约，更不代表已收款。
2. **单量假设**：已完成并可计价的订单情景，不代表未来订单。
3. **退款后收入**：报价 × 单量 × (1−假设退款比例)；未额外考虑坏账、延迟回款。
4. **直接成本**：模型/API、工具、材料、外包、必要购买等，可以订单为单位。
5. **获客现金支出**：广告费等期间花费，即便没有成交也可能发生。
6. **人工时间**：制作、沟通、返工，加上**未成交线索的时间**。
7. **现金结余**：扣除部分现金成本与假设预留后的情景数值，**还没给自己的劳动计价**。
8. **计入劳动机会成本后的差额**：现金结余 − 总投入小时 × 自定义小时价值；仍不是法定税务利润。

## 可复算公式

设：
- p = 假设单价；n = 假设完成订单数；d = 每单直接现金成本
- f = 平台费率；r = 退款占比；F = 固定费用；A = 获客现金支出
- h = 每单制作工时；c = 每单沟通/获客工时；w = 每单返工预留工时
- u = **未成交线索/空转**总工时；v = 自定义个人劳动时间价值（元/小时）
- t = 其他费用/税费**演示预留比例**（只针对正的现金贡献计提）

那么：

- 开票金额情景 = p × n
- 退款后收入 = p × n × (1−r)
- 平台手续费情景 = p × n × f（注意：真实平台收费规则可能不同）
- **现金贡献** = 退款后收入 − d×n − F − A − 平台手续费
- **预留后现金结余** = 现金贡献 − max(现金贡献, 0) × t
- **总投入工时** = n×(h+c+w) + u
- **劳动价值估算** = 总投入工时 × v
- **计入劳动后的差额** = 预留后现金结余 − 劳动价值估算

额外显示「**不含预留的人工保本单价**」= (d×n + F + A + 劳动价值估算) ÷ [n×(1−r−f)]。若 n=0 或 r+f≥100%，则该保本单价不存在。**这个保本价没有计税费预留、坏账、平台差异和最终法律责任，不能直接拿去报价。**

## 一组反例：看似赚钱，计时后可能亏损

假设 p=1000，n=2，d=100，F=100，A=50，h=2，c=1，w=1，u=2，v=100，退款0%，手续费0%，预留10%。

- 报价合计：2000 元
- 现金贡献：1650 元
- 预留后现金结余：1485 元
- **总真实投入：10 小时**；小时现金结余：148.50 元
- 劳动价值：1000 元；计入劳动后差额：**485 元**
- 不计预留的人工保本单价：675 元/单（纯演示）

如果实际报价变低、未成交获客变多、客户反复返工或退款增加，该差额可能转为负值。

## 五项不确定性

- 有的订单中途取消不等于“整单按比例退款”；模型是近似。
- 平台手续费可能按实收、含税或有最低费用；本模型按报价总额近似。
- “税费/其他预留”**不是**真实税率，不应当作税务建议。
- 本模型没有概率、市场平均价或客单价分布，不能预测未来收益。
- 不得输入可识别客户隐私；网站使用前端计算，不上传这些表单数据。

**对抗式测试：**必须覆盖 100% 退款、0 笔成交、负数输入、100% 预留、支付费与退款叠加，并在 GitHub CI 中执行。
