- **P0** AI假案例与假收款 → 案例明确作者自述和未独立核实
- **P0** 事实依据与官网来源 → 10个官方资源入口，所有产品声明追溯到原文
- **P0** 泄露客户机密 → 全部提示词要求授权/脱敏/人工终审
- **P0** 虚构履历与评价 → 所有职业服务和营销章节禁止编造经历/评价
- **P1** 报价与利润公式 → 交互计算器显式区分报价、笔数、成本、工时、税费
- **P1** 服务可交付定义 → 10套服务包含输入、产物、风险、示例报价
- **P1** 散弹式引流 → 获客章节明确遵守平台规则，反对骚扰
- **P1** 套餐/API混淆 → API与订阅分开计费，功能权限随账户变化
- **P1** 错误数据输入 → 资料来源与内容需人工核验
- **P1** 移动端可用性 → 响应式布局 + 搜索/筛选/复制
- **P1** 版权来源与开源协议 → 本站原创文本MIT；第三方标识非转授权
- **P1** 没有证据的案例 → 自述案例标签与证据等级分离
- **P1** 页面转化体验 → 首屏/中部/底部留微信与官网且不劫持阅读
- **P1** 无后端隐私承诺 → 只存本地localStorage，不连接销售CRM
- **P2** 维护体系 → 贡献指南、ISSUE模板、事实复核日期、CI内容测试
- **P0** 忽略获客成本、沟通工时与退款 → 补成交本维度与对账提醒，避免利润公式误导

- **P1** 每个服务包的可验收SOP过浅 → 10个服务包补齐范围、除外事项、变更控制、修改次数和证据
- **P1** 课程步骤通用重复，缺少端到端样本 → 新增8章高频难题教程、4个可复现模拟场景

**不足与剩余风险：**并无逐项真实付费交付验证，也无税务或法规适用地区的实地检查，不能宣传全网第一。详见 [审核方法](QUALITY-METHOD.md)。
