# 客户资料处理：入场审查与事故处置 SOP

## 禁止默认上传的材料
未经客户或所在组织授权的聊天记录、联系人、证件、账户密钥、薪资名单、受法律或合同保护的数据，不得随意粘贴到任何个人工具账户。脱敏不是万能：可组合识别身份的字段仍有风险。

## 五个决定
1. **归属**：资料是谁的？有无书面授权、合同或组织工具政策？
2. **必要性**：能否用模拟数据跑通？能否只用汇总字段？
3. **产品环境**：确认订阅类型、数据控制选项、工作区权限与共享链接范围；不能推定所有套餐相同。
4. **执行边界**：确定谁能查看、允许保留多久、由谁负责删除，以及是否需要人工审核。
5. **异常响应**：误上传立即停止继续处理、保存非敏感事件记录、通知客户授权联系人并根据规定评估后续处置；不要擅自承诺已经完全删除。

## 分享前再次检查
个人账户共享对话链接可能被任何持链接者查看。发布前审查历史上下文、附件与潜在身份信息，按需撤销旧链接。企业工作区权限与个人链接不同，以官方说明为准。

## 使用范围
本页面工具不向服务器发送问卷输入，只在本地生成建议。任何“允许/不允许”的判断都不能代替实际客户许可、合同与组织政策。
