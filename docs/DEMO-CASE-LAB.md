# 四个可复现的模拟交付案例


> **全部模拟、全部无真实成交**：可用于体验工作流，禁止写成客户案例或收入证明。



## 01 · 模拟：餐饮门店30条常见问题整理

**性质：**教学演示 / 非真实订单

**输入：**虚构门店营业时间、预约方式、退订政策样例（均为演示数据）

**操作：**先确定哪些问题有官方答案，再写FAQ与转人工规则

**预期交付：**30条FAQ草案+8条需要客户确认的政策问题+人工升级流程

**人工验收：**逐条对照已批准政策；8条未知不得自行补写

**失败模式：**模型可能自行编造退款时限，改为「待门店确认」

**证据：**仓库演示资料，无客户订单、付款或真实效果证据


## 02 · 模拟：一份真实履历事实的岗位适配练习

**性质：**教学演示 / 非真实订单

**输入：**虚构求职者两段岗位经历与公开职位JD（演示占位数据）

**操作：**事实核对→JD需求映射→STAR问答→人工审校

**预期交付：**岗位匹配证据表+简历修订清单+6道面试准备题

**人工验收：**检查每一条工作成绩均来自已确认输入，缺失部分留空

**失败模式：**模型可能过度包装项目职责，遇到无证据的领导经历必须删除

**证据：**虚构资料，非真实候选人或Offer


## 03 · 模拟：Excel月报异常核查

**性质：**教学演示 / 非真实订单

**输入：**本项目自造的10行虚构订单数据，故意放入重复行、空值与退款

**操作：**定义净收入→标记异常→抽样复算→生成说明

**预期交付：**1页异常周报+指标定义表+异常处理记录

**人工验收：**订单按唯一ID去重、退款计减项、缺失价格不补0冒充已收

**失败模式：**总额看似正确但漏了退款或重复值：必须人工抽样复算

**证据：**全部数据均为生成的演示数据


## 04 · 模拟：短视频选题从假设到验收

**性质：**教学演示 / 非真实订单

**输入：**虚构账号定位、3条已有视频摘要与假设读者问题

**操作：**提炼选题→写3版脚本→检查事实与夸大承诺

**预期交付：**10条选题卡+3条脚本+免责声明和拍摄清单

**人工验收：**不虚构历史播放数据；结果只承诺交付脚本

**失败模式：**如果输出“必爆”“必涨粉”，删去并改为可测试假设

**证据：**模拟选题，无实测发布或流量数据
