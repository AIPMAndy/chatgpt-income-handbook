# 案例公开与收入证据标准：宁缺毋滥

这个项目的核心防伪原则：**演示材料、本人自述、客户签收、独立验证分别贴标签。** 不要把“有聊天截图”“AI 生成样品”“收到咨询”自动等同于“成交”“回款”“产生利润”。

| 等级 | 最低证据 | 允许使用的表述 | 不可使用的表述 |
| --- | --- | --- | --- |
| D — 模拟 | 公开的虚构输入、版本化产物、操作步骤 | “模拟案例”“演示输出” | “客户买单”“我赚了 X 元” |
| C — 作者自述 | 作者描述过程，但仓库不展示独立可验证材料 | “作者自述，未独立核实” | “经独立验证”“所有人可复制” |
| B — 客户验收 | 客户授权的验收或签收材料、范围与日期；不可公开原件时如实说明 | “客户确认收到/验收 X 范围，证据未公开” | 自动宣称已付款、已盈利 |
| A — 可公开复核 | **客户明确同意公开**、可核实产物或公开证据、证据与具体范围一一对应 | “公开证据支持的具体结论” | 推导成交率或未来收益保证 |

## 发布前的九问

1. **这件事真的发生了吗？** 日期、场景和主体能否区分演示与现实？
2. **有没有许可？** 客户是否明确同意公开姓名、截图、金额、交付样例和时间？
3. **成交定义是什么？** 咨询/意向/口头同意/签约/收款/验收/回款必须分开。
4. **数字可复算吗？** 金额是含税/不含税？是否扣退款、返工、费用和人工？
5. **因果有证据吗？** “使用过 ChatGPT”不等于“ChatGPT 导致全部收入”。
6. **是否夸大样本？** 一例成交不能宣传成可重复的转换率，更不能暗示人人赚钱。
7. **是否有不可披露信息？** 身份、通讯信息、客户内部数据、第三方作品需遮蔽/授权。
8. **是否可撤销？** 客户撤回许可或事实被证伪后，如何定位和纠正页面/截图？
9. **失效日期是什么？** 产品功能、套餐、政策、市场说法必须标记核验日期。

## 贡献时提交什么

使用 [案例模板](../templates/CASE-STUDY.md)，另附经授权可公开的原始事实摘要、样例产物、验收记录、适用范围、记录日期、失败点和修订历史。若不能公开证据，保留 C/B 相应标记，不需要上传隐私来换评级。

### 高风险文案判定举例

- “我用 ChatGPT 一天赚一千” → **拒收**，除非有可公开核查的具体订单、实际成本及收入归因依据；即便真实，也不能当成他人收入预测。
- “这是我设计的模拟客户 FAQ，展示可交付格式” → **可发布**，须明确没有真实订单。
- “我整理了客户允许公开的产品 FAQ，共 30 项，客户已确认格式” → **需核实授权与签收材料**，只写证据支持的范围。
- “这个方法保证每人七天变现” → **永不接受**。

社区欢迎真实失败案例：未成交的需求访谈、返工造成亏损、客户取消、自动化失败，往往更有参考价值。不得诱导贡献者泄露客户资料。

此标准是内容治理规则，不能替代相关司法辖区的法律、广告合规或客户合同。
